About WAFU

Tanjung Api Airport (OJU) is a small airport in Tojo Una-Una, Indonesia, with the ICAO code WAFU. It has one runway, 12/30, 6,070 ft long, with a hard surface. The OpenStreetMap layout shows 6 taxiway segments, 1 aprons and 2 terminal outlines. The route snapshot of 14 Oct 2026 has no scheduled routes for WAFU.
