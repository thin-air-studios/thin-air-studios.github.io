Map, place and weather data

OpenStreetMap

Airport maps, coastlines, water and peaks © OpenStreetMap contributors. Available under the Open Database Licence (ODbL) 1.0. Map data is fetched through the Overpass API. The map data bundled with the app, for the 50 busiest airports, Midland (KMAF) and Lukla (VNLK), is an extract of OpenStreetMap data and remains available under the ODbL. The extracts are published in full, in machine-readable JSON, at https://thin-air-studios.github.io/osm/. You can also ask us for a copy by email at thinaircapital@gmail.com. More: openstreetmap.org/copyright

Time zones

Each airport's time zone comes from timezone-boundary-builder by Evan Siroky, whose output is derived from OpenStreetMap and licensed under the ODbL 1.0. The lookup code is tz-lookup 11.7.0 by PhotoStructure, a fork of darkskyapp/tz-lookup, released under CC0 1.0 Universal (public domain dedication). The time-zone data inside it is © OpenStreetMap contributors (ODbL 1.0).

Airports and runways

OurAirports (ourairports.com). Public domain.

World's busiest airports

Passenger rankings: ACI World, 2025 airport traffic results. Used to choose and order the world's 50 busiest airports. ACI World is not affiliated with Short Final.

Live feed

Live flight positions: adsb.lol (adsb.lol), an open API for ADS-B aircraft data, available under the Open Database Licence (ODbL) 1.0. More: adsb.lol API.

The OpenSky Network (opensky-network.org) is also named here, because the game can use it as a fallback for live flights. The fallback is not used unless the game's server allows it, and only when adsb.lol does not answer.

Flight routes

Flight routes: Virtual Radar Server standing data, CC0 1.0. The game's route files are made from the standing data at github.com/vradarserver/standing-data, published by Virtual Radar Server under CC0 1.0 Universal (the public domain dedication, below). Thanks to the Virtual Radar Server users who submitted the routes, and to Andrew Whewell, who maintains the data. The game uses the routes to show the city a real plane came from, when it lands at the airport being played.

Weather

aviationweather.gov, Aviation Weather Center, NOAA / US National Weather Service. US government data, public domain.

World map (World stats)

The land on the World stats map is Natural Earth's 110m land outline (naturalearthdata.com), public domain. It is taken from the world-atlas package (Michael Bostock; the package's own licence is ISC), simplified for the map and drawn as one path in game/js/worldmap.js. Natural Earth asks no credit, and this one is given with thanks.
